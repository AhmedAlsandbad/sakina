# سكينة قرآن

**سكينة قرآن** موقع عربي مجاني للاستماع إلى القرآن الكريم وإذاعات القرآن المباشرة، وتصفح السور والقراء، والرقية الشرعية، والأذكار، ومواقيت الصلاة.

الموقع الرسمي: **https://sakinaquran.net/**

## الأقسام الرئيسية

- القرآن الكريم: https://sakinaquran.net/quran/
- قراء القرآن: https://sakinaquran.net/reciters/
- سور القرآن: https://sakinaquran.net/surahs/
- إذاعات القرآن الكريم: https://sakinaquran.net/radio/
- الرقية الشرعية: https://sakinaquran.net/ruqyah/
- الأذكار: https://sakinaquran.net/adhkar/
- مواقيت الصلاة: https://sakinaquran.net/prayer-times/

المشروع Static/PWA خفيف ومصمم للعمل بسرعة على الهاتف، مع عدم تحميل ملفات الصوت إلا عند بدء التشغيل.
